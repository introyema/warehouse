# Як додавати та редагувати проєкти (через файл data/projects.js)

> Це спосіб **без Supabase**. Якщо ви налаштували адмін-панель (див. [ADMIN_SETUP.md](ADMIN_SETUP.md)), проєкти додаються там, а `data/projects.js` лишається лише запасним варіантом.

Усі проєкти описані в одному файлі: **`data/projects.js`**. Кожен проєкт — це блок між `{` і `}`, після якого стоїть кома. Картка в каталозі, сторінка проєкту, пошук і фільтр створюються з цього запису автоматично. Змінювати HTML, CSS чи JavaScript не потрібно.

Правила, які варто знати перед початком:

- Текст завжди пишіть у лапках `"так"`. Між полями ставте коми.
- Кожне поле має вигляд `назва: "значення",`.
- Необов'язкове поле можна не писати або залишити порожнім `""`. Порожні блоки та кнопки на сайті не показуються.
- Якщо в записі є помилка (немає `id` чи `title`, повторюється `id`), цей проєкт пропускається, а решта каталогу працює. Подробиці видно в консолі браузера (клавіша F12, вкладка Console).

## Де що лежить

| Що | Де |
|---|---|
| Список проєктів | `data/projects.js` |
| Назва сайту, GitHub, «Про автора» | `data/site.js` |
| Обкладинки та скриншоти | `images/projects/<id-проєкту>/` |
| Заглушка, коли немає зображення | `images/placeholder.svg` (не чіпайте) |
| Архіви з модами й українізаторами | **не в репозиторії**, а в GitHub Releases (див. нижче) |

Для кожного проєкту створіть власну папку з назвою, що збігається з його `id`. Наприклад, `images/projects/million-depth/`, а в ній `cover.jpg` та `screenshots/01-menu.jpg`.

## Усі поля запису

| Поле | Обов'язкове? | Пояснення |
|---|---|---|
| `id` | **так** | Унікальне ім'я латиницею без пробілів, напр. `million-depth` |
| `title` | **так** | Назва проєкту |
| `category` | **так** | `ukrainizer`, `mod`, `addon`, `tool` або `other` |
| `game` | ні | Назва гри |
| `shortDescription` | ні | Короткий опис для картки (1–2 речення) |
| `description` | ні | Повний опис для сторінки проєкту |
| `cover` | ні | Головна обкладинка. Порожнє — буде заглушка |
| `screenshots` | ні | Список скриншотів (див. нижче) |
| `status` | ні | `done` — Завершено, `wip` — У розробці, `archived` — Архівний |
| `version` | ні | Напр. `"1.0"` |
| `updatedAt` | ні | Дата `РІК-МІСЯЦЬ-ДЕНЬ`, напр. `"2025-03-20"` |
| `compatibility` | ні | З якою версією гри працює |
| `features` | ні | Список особливостей (для українізатора — «Особливості перекладу») |
| `changes` | ні | Список: що саме змінює мод |
| `requirements` | ні | Вимоги, текст |
| `dependencies` | ні | Список: необхідні залежності (інші моди, програми) |
| `conflicts` | ні | Список: відомі конфлікти з іншими модами |
| `installation` | ні | Список кроків встановлення |
| `downloadUrl` | ні | Пряме посилання на файл. Без нього кнопки «Завантажити» не буде |
| `sourceUrl` | ні | Вихідний код або сторінка проєкту (окреме від `downloadUrl`) |
| `guideUrl` | ні | Посилання на окрему інструкцію |
| `detailsUrl` | ні | Якщо заповнити, «Докладніше» веде на цю адресу, а не на сторінку сайту |
| `credits` | ні | Авторство та використані сторонні матеріали (текст або список) |
| `author`, `license` | ні | Автор і ліцензія |
| `example` | ні | `true` — позначка «Приклад». У справжніх проєктах цей рядок **видаліть** |

Список записується у квадратних дужках: `features: ["Перше", "Друге"],`.

Скриншоти записуються так (підпис `caption` і `alt` необов'язкові, `alt` — це опис для людей, які не бачать зображення):

```js
screenshots: [
  { src: "images/projects/million-depth/screenshots/01-menu.jpg", caption: "Головне меню", alt: "Головне меню гри українською" },
  { src: "images/projects/million-depth/screenshots/02-dialog.jpg", caption: "Діалог" }
],
```

Додати скриншот — додайте ще один рядок `{ src: ... },`. Видалити — видаліть рядок. Логіка галереї від цього не залежить.

## А. Як додати українізатор Million Depth

У каталозі вже є **приклад-заготовка** `million-depth-example` з позначкою «Приклад». Її можна відредагувати. У ній немає жодних реальних посилань, версій чи сумісності: усе це ви вписуєте самі.

**1. Підготуйте зображення.**
Створіть папку `images/projects/million-depth/`.
- Обкладинка: `images/projects/million-depth/cover.jpg` (16:9, напр. 1280×720, до 300 КБ).
- Скриншоти перекладу: `images/projects/million-depth/screenshots/01-menu.jpg`, `02-dialog.jpg` тощо. Знімайте саме результат перекладу: меню, діалоги, інтерфейс гри. Використовуйте тільки власні скриншоти.

Файли на GitHub додаються так: відкрийте репозиторій → папку `images/projects` → **Add file → Upload files**. Щоб створити нову папку, у назві файлу введіть шлях з косою рискою, напр. `million-depth/cover.jpg`. Потім натисніть **Commit changes**.

**2. Підготуйте архів.**
Покладіть у папку файли українізатора так, як їх треба розпакувати в гру, додайте короткий текстовий файл `README.txt` з інструкцією й стисніть у `.zip` (у Windows: правий клік → «Надіслати» → «Стиснена ZIP-папка»). Назвіть, наприклад, `MillionDepth-UA-v0.1.zip`. Додавайте лише власні файли та ті, які можна розповсюджувати. Не додавайте файли гри.

**3. Розмістіть архів і отримайте пряме посилання (GitHub Releases).**
1. На сторінці репозиторію праворуч натисніть **Releases** → **Create a new release** (або **Draft a new release**).
2. У полі **Choose a tag** введіть, наприклад, `million-depth-v0.1` і підтвердьте створення тегу.
3. Заголовок: «Million Depth — український переклад v0.1».
4. Перетягніть `.zip` у блок **Attach binaries**.
5. Натисніть **Publish release**.
6. На сторінці релізу правою кнопкою миші на назві `.zip` у списку **Assets** оберіть «Копіювати адресу посилання». Це і є пряме посилання. Воно виглядає як `https://github.com/ІМ'Я/РЕПОЗИТОРІЙ/releases/download/ТЕГ/файл.zip`. Підійде й інший хостинг, якщо він дає посилання на сам файл.

**4. Заповніть запис у `data/projects.js`.** Знайдіть блок `million-depth-example` (або скопіюйте шаблон з розділу «Шаблони» нижче) і змініть:

```js
{
  id: "million-depth",
  title: "Український переклад Million Depth",
  game: "Million Depth",
  category: "ukrainizer",
  shortDescription: "Ваш короткий опис.",
  description: "Ваш повний опис.",
  cover: "images/projects/million-depth/cover.jpg",
  screenshots: [
    { src: "images/projects/million-depth/screenshots/01-menu.jpg", caption: "Головне меню", alt: "Головне меню гри українською" },
    { src: "images/projects/million-depth/screenshots/02-dialog.jpg", caption: "Діалог" }
  ],
  status: "wip",
  version: "0.1",
  updatedAt: "2025-03-20",
  compatibility: "Версія гри, з якою ви перевіряли",
  features: ["Перекладено меню", "Перекладено діалоги"],
  installation: [
    "Завантажте архів.",
    "Розпакуйте його у папку з грою (вкажіть точний шлях).",
    "Запустіть гру."
  ],
  downloadUrl: "ПОСИЛАННЯ, СКОПІЙОВАНЕ З GITHUB RELEASES",
  sourceUrl: "",
  credits: "Хто що робив; які сторонні матеріали використано"
},
```

Рядок `example: true` має бути **видалений**. Вписуйте тільки правду: ту сумісність і версію, що ви справді перевірили.

**5. Перевірте** (див. розділ «Г»): картка в каталозі має показати обкладинку й кнопку «Завантажити»; у «Докладніше» мають працювати галерея (клік по скриншоту відкриває велике зображення) та кнопка «Завантажити українізатор». Перейдіть за посиланням, щоб переконатися, що файл завантажується.

## Б. Як додати мод для гри

1. Створіть папку `images/projects/мій-мод/` (назва = `id`) і покладіть туди `cover.jpg` та скриншоти `screenshots/01.jpg`, ... Скриншоти мають показувати мод у грі.
2. Заархівуйте мод у `.zip` і завантажте в **Releases** (див. А, крок 3). Скопіюйте пряме посилання.
3. Скопіюйте шаблон мода (нижче) у `data/projects.js` під останній блок. Заповніть: `id` (унікальний), `title`, `game`, `category: "mod"`, описи, `version`, `compatibility`, `dependencies`, `conflicts`, `installation`, `downloadUrl`.
4. Категорія `"mod"` автоматично додає проєкт у фільтр «Моди». Перевірте: відкрийте сайт, натисніть «Моди», а потім спробуйте знайти проєкт за назвою у пошуку.

## В. Як редагувати та видаляти проєкт

Усі зміни робляться у файлі `data/projects.js`. Нижче всі приклади на проєкті `million-depth`.

- **Змінити назву чи опис.** Знайдіть блок з `id: "million-depth"`, змініть текст у полях `title`, `shortDescription` чи `description`. Не змінюйте `id`, інакше старі посилання на сторінку проєкту перестануть працювати.
- **Оновити файл.** Створіть у Releases новий реліз із новим архівом (наприклад, тег `million-depth-v0.2`), скопіюйте нове посилання, вставте в `downloadUrl` і змініть `version` та `updatedAt`.
- **Додати скриншот.** Завантажте файл у `images/projects/million-depth/screenshots/` і додайте рядок `{ src: "images/projects/million-depth/screenshots/03-new.jpg", caption: "Підпис" },` у список `screenshots`.
- **Видалити скриншот.** Видаліть його рядок зі списку `screenshots`. За бажанням видаліть і сам файл у `images/projects/...`.
- **Змінити категорію.** Змініть значення `category` (напр. з `"mod"` на `"addon"`). Проєкт сам перейде в потрібний фільтр. **Змінити статус** — поле `status`.
- **Видалити проєкт.** 1) Видаліть увесь блок від `{` до `},`. 2) Видаліть його папку зображень `images/projects/million-depth/`. 3) За бажанням видаліть реліз на GitHub (Releases → ваш реліз → Delete). Інші частини сайту посилаються на проєкт лише через цей запис, тож битих посилань не залишиться. Лише якщо ви десь розмістили пряме посилання на `#/project/...` зовні, воно покаже «Проєкт не знайдено».

## Г. Як оновлювати сайт

1. Відкрийте репозиторій на github.com і перейдіть до файлу (наприклад, `data/projects.js`).
2. Натисніть значок олівця (**Edit this file**), змініть текст.
3. Натисніть **Commit changes…** (це «зберегти»), потім ще раз **Commit changes**.
4. Зачекайте 1–3 хвилини: GitHub Pages сам оновить сайт. Статус можна побачити у вкладці **Actions** (зелена позначка — готово).
5. Відкрийте свій сайт і натисніть Ctrl+F5, щоб побачити свіжу версію. Перевірте: картку в каталозі, фільтр, пошук, «Докладніше», галерею та кнопку «Завантажити».

**Якщо сайт став порожнім або проєкт не з'явився.** У `data/projects.js` швидше за все, забута кома чи лапка, або повторюється `id`. Відкрийте сайт, натисніть F12 → Console, і там буде вказано помилку. Перевірити сайт на своєму комп'ютері можна ще до збереження на GitHub: після завантаження репозиторію відкрийте `index.html` у браузері.

## Шаблони

### Шаблон українізатора

Обов'язково лише `id`, `title`, `category`. Решту заповнюйте за потреби або видаляйте рядок.

```js
{
  id: "назва-латиницею",               // ОБОВ'ЯЗКОВО, унікальний
  title: "Назва українізатора",        // ОБОВ'ЯЗКОВО
  category: "ukrainizer",              // ОБОВ'ЯЗКОВО
  game: "Назва гри",
  shortDescription: "Короткий опис для картки.",
  description: "Повний опис: що перекладено, у якому стані переклад.",
  cover: "images/projects/назва-латиницею/cover.jpg",
  screenshots: [
    { src: "images/projects/назва-латиницею/screenshots/01-menu.jpg", caption: "Меню", alt: "Меню гри українською" }
  ],
  status: "wip",                       // done | wip | archived
  version: "1.0",
  updatedAt: "2025-01-31",
  compatibility: "Версія гри, з якою перевірено",
  features: ["Особливість перекладу 1", "Особливість 2"],
  installation: ["Крок 1", "Крок 2"],
  requirements: "",
  downloadUrl: "",                     // пряме посилання на архів
  sourceUrl: "",                       // вихідний код / сторінка проєкту
  credits: "Автори та використані матеріали"
},
```
